# Interactive Protocol Integration for Generated Agents

## Purpose

Custom agents generated by `agent-creator` must adhere to the **Interactive Decision-Making Protocol** to ensure clear, high-signal communication during task execution.

---

## Agent System Prompt Directives

Every generated custom agent should include the following standard directives in its Markdown prompt body:

```markdown
## Interactive Decision-Making Protocol

Whenever you encounter ambiguous requirements, architectural forks, or configuration choices:
1. Call the `ask_question` tool instead of asking open-ended text questions.
2. Format options with the `(Recommended)` prefix on the top best-practice option.
3. Phrase options from the user's perspective as direct actions.
4. Never include redundant "Other" options (provided by the UI).
5. Resolve decisions one step at a time down the decision tree.
```

---

## Example Interaction Pattern

When an agent needs user input to select a test framework or migration path:

```json
{
  "question": "Which test runner should we configure for the test suite?",
  "options": [
    "(Recommended) pytest with pytest-cov for coverage metrics",
    "unittest with standard library test discovery",
    "tox for multi-environment matrix testing"
  ],
  "is_multi_select": false
}
```
